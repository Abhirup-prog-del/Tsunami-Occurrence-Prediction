# 🌊 Tsunami Predictor

Predicts whether an earthquake will trigger a tsunami using seismic and geographic features (magnitude, depth, location, and more). Compares tuned Decision Tree, Random Forest, and XGBoost classifiers — best model reaches **0.947 ROC AUC**.

## Overview

Tsunamis are most commonly generated by large undersea earthquakes, but not every earthquake produces one. This project frames tsunami occurrence as a **binary classification problem**: given an earthquake's magnitude, depth, location, and other seismic readings, predict whether it caused a tsunami (`1`) or not (`0`).

The notebook covers the full ML workflow:
1. Data acquisition and exploration
2. Exploratory data analysis (distributions, outliers, correlations)
3. Train/test splitting with stratification
4. Model training (baseline) for three algorithms
5. Hyperparameter tuning via `GridSearchCV`
6. Model evaluation and comparison
7. Feature importance analysis

## Dataset

- **Source:** [Global Earthquake Tsunami Risk Assessment Dataset](https://www.kaggle.com/datasets/ahmeduzaki/global-earthquake-tsunami-risk-assessment-dataset) (Kaggle, via `kagglehub`)
- **Size:** 782 earthquake records, 13 columns
- **Target variable:** `tsunami` (0 = no tsunami, 1 = tsunami)
- **Class balance:** 478 no-tsunami events (61.1%) vs. 304 tsunami events (38.9%) — moderately imbalanced

### Features used

| Feature | Description |
|---|---|
| `magnitude` | Earthquake magnitude |
| `cdi` | Community Determined Intensity |
| `mmi` | Modified Mercalli Intensity |
| `sig` | Significance score of the event |
| `nst` | Number of seismic stations that reported the event |
| `dmin` | Horizontal distance to the nearest station |
| `gap` | Largest azimuthal gap between stations |
| `depth` | Depth of the earthquake (km) |
| `latitude` / `longitude` | Epicenter coordinates |
| `Month` | Month the event occurred |

`Year` is dropped prior to modeling to avoid the model learning a spurious time trend instead of physical earthquake characteristics.

## Methodology

- **Split:** 80/20 train-test split, stratified on `tsunami` to preserve class ratio (important given the moderate class imbalance and small dataset size)
- **Tuning:** `GridSearchCV` with 5-fold cross-validation, optimizing for **ROC AUC**
- **Evaluation metrics:** Accuracy, Precision, Recall, F1-Score, ROC AUC, and Confusion Matrices

### Why ROC AUC and Recall matter most here

For tsunami prediction, **missing a real tsunami (false negative) is far more dangerous than a false alarm (false positive)**. A missed warning can cost lives, while a false alarm is a comparatively minor inconvenience. Because of this, the notebook explicitly evaluates models by both:
- **ROC AUC** — the most robust overall measure of classification performance across thresholds
- **Recall** — the most operationally critical metric, since it measures the model's ability to catch actual tsunami events

## Results

### Final model comparison

| Model | Accuracy | Precision | Recall | F1-Score | ROC AUC |
|---|---|---|---|---|---|
| Decision Tree (Initial) | 0.8662 | 0.8030 | 0.8689 | 0.8346 | 0.8667 |
| Decision Tree (Tuned) | 0.8854 | 0.8644 | 0.8361 | 0.8500 | 0.9022 |
| Random Forest (Initial) | 0.9045 | 0.8710 | 0.8852 | 0.8780 | 0.9395 |
| Random Forest (Tuned) | 0.8981 | 0.8571 | 0.8852 | 0.8710 | 0.9389 |
| XGBoost (Initial) | 0.9045 | 0.8594 | **0.9016** | 0.8800 | 0.9443 |
| **XGBoost (Tuned)** | 0.8981 | 0.8571 | 0.8852 | 0.8710 | **0.9467** |

- 🏆 **Best model by ROC AUC:** XGBoost (Tuned) — **0.9467**
- 🚨 **Best model by Recall:** XGBoost (Initial) — **0.9016** (catches ~90% of actual tsunami-causing earthquakes)

### Best hyperparameters found

| Model | Best Parameters | CV ROC AUC |
|---|---|---|
| Decision Tree | `max_depth=5`, `min_samples_leaf=2`, `min_samples_split=5` | 0.9084 |
| Random Forest | `max_depth=None`, `min_samples_leaf=1`, `min_samples_split=5`, `n_estimators=200` | 0.9389 |
| XGBoost | `learning_rate=0.1`, `max_depth=3`, `n_estimators=100`, `subsample=1.0` | 0.9512 |

### Key takeaways

- **XGBoost consistently outperforms** Decision Tree and Random Forest on ROC AUC, making it the most reliable model overall for distinguishing tsunami vs. non-tsunami earthquakes.
- **Random Forest and XGBoost are close competitors**, both comfortably ahead of the single Decision Tree, showing that ensemble methods add real value on this dataset.
- Tuning improved the Decision Tree noticeably (ROC AUC 0.867 → 0.902) but had a smaller or mixed effect on the ensemble models, suggesting their default settings were already close to optimal for this dataset size.
- Feature importance analysis (see notebook) highlights which seismic characteristics — such as magnitude, depth, and significance score — drive predictions the most, offering interpretability alongside raw performance.

## How this is helpful

- **Early-warning support:** A high-recall model like this can act as a decision-support layer in earthquake monitoring systems, flagging events with high tsunami likelihood for rapid human review and alert issuance.
- **Resource prioritization:** Disaster response agencies can use tsunami-probability scores to prioritize which coastal regions need immediate alerts versus lower-priority monitoring.
- **Feature-driven insight:** Feature importance results help geophysicists and emergency planners understand which measurable earthquake properties (e.g., magnitude, depth, seismic gap) are most predictive of tsunami risk, informing sensor placement and monitoring priorities.
- **Benchmark for further research:** The notebook's structured comparison of baseline vs. tuned models across three algorithm families provides a reusable template for benchmarking future models or additional data sources (e.g., ocean-floor sensors, historical tsunami records).

> ⚠️ **Disclaimer:** This is a research/educational project trained on a small (782-row) historical dataset. It is **not** a validated early-warning system and should not be used as a sole basis for real-world tsunami alerts or safety decisions.
